AI-Based Diabetes Risk Prediction

Enter eight health measurements and see what a trained Logistic Regression model estimates, together with charts that put your values next to the training data.

Start health assessment View dashboard
Important: this is an experimental educational project. Its output is a statistical model score, not a medical diagnosis. It cannot replace a clinician, laboratory tests or professional advice.
About the system

A Flask web app that loads a model trained on the Pima Indians Diabetes Dataset (768 records of women aged 21+). It was built to demonstrate an end-to-end ML workflow.

How it works
  1. You submit 8 measurements.
  2. Inputs are validated on the server.
  3. The saved preprocessing pipeline prepares them exactly as in training.
  4. The model returns a class and a score.
Key features
  • Validated assessment form
  • Probability gauge and comparison chart
  • Prediction history stored in SQLite
  • Dashboard of your stored predictions

Known limitations
  • Trained on a small dataset from one population; results may not apply to other people.
  • Some values in the original data (notably insulin and skin thickness) were missing and were filled with medians.
  • The score is not a calibrated probability of having diabetes.
