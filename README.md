# DiabetesRisk AI – AI-Based Diabetes Risk Prediction

## Project Overview
DiabetesRisk AI is a machine learning-based web application developed using Python and Flask. It predicts diabetes-related outcomes based on user-provided health parameters using a Logistic Regression model.

## Features
- User-friendly health assessment interface
- Machine Learning-based prediction
- Prediction score visualization
- Comparison of user values with training data
- Prediction history management
- Dashboard for prediction insights

## Technologies Used
- Python
- Flask
- Scikit-learn
- Pandas
- NumPy
- HTML, CSS, JavaScript
- SQLite
- Matplotlib

## Machine Learning
- Algorithm: Logistic Regression
- Dataset: Public diabetes dataset
- Preprocessing and model pipeline

## Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/Hari585133/diabetes-risk-ai.git
```

2. Navigate to the project folder:

```bash
cd diabetes-risk-ai
```

3. Create a virtual environment:

```bash
python -m venv venv
```

4. Activate the environment:

```bash
venv\Scripts\activate
```

5. Install dependencies:

```bash
pip install -r requirements.txt
```

6. Run the application:

```bash
python app.py
```

7. Open in your browser:

```text
http://127.0.0.1:5000
```

## Disclaimer
This application is an experimental educational prototype. Its predictions are not medical diagnoses and must not be used for clinical or healthcare decisions.
